COMPANY VERIFICATION DEMO

This is an unofficial front-end demonstration only. It is not affiliated with the Sri Lankan Registrar of Companies and is not connected to any government database. It must not be presented as an official verification service.

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern web browser.

SAMPLE DATA
PV00273539 is a hard-coded demonstration record in script.js. Edit the sampleRecords object to change the demonstration data. No real verification occurs.
